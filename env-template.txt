# Environment Variables Template for PDF Export with Vercel Blob Storage

# Vercel Blob Token (automatically provided in Vercel deployments)
# BLOB_READ_WRITE_TOKEN=vercel_blob_token_here

# Optional: Custom Puppeteer executable path for specific hosting platforms
# PUPPETEER_EXECUTABLE_PATH=/usr/bin/google-chrome-stable

# Optional: Skip Chromium download for platforms that provide Chrome
# PUPPETEER_SKIP_CHROMIUM_DOWNLOAD=true

# Instructions:
# 1. No additional setup required! Vercel Blob works automatically
# 2. BLOB_READ_WRITE_TOKEN is automatically provided in Vercel deployments
# 3. For local development, you can get a token from: https://vercel.com/dashboard/stores
# 4. Files are automatically cleaned up by Vercel Blob
# 5. Deploy to Vercel and PDF exports will work immediately!

# Local Development Setup (optional):
# 1. Go to https://vercel.com/dashboard/stores
# 2. Create a Blob store or use existing
# 3. Copy the token and add to your .env.local:
#    BLOB_READ_WRITE_TOKEN=your_token_here
